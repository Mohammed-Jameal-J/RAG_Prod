# PDF Chat

A Streamlit app that lets you upload one or more PDFs and ask questions about them in plain language. Answers are generated by an LLM using **only** content retrieved from your documents — not the model's general knowledge — so it says "I couldn't find that in the document" instead of guessing.

**Live app:** https://rag-prod-d7ua.onrender.com
*(hosted on Render's free tier — the first request after a period of inactivity can take 30–60s while the instance wakes up)*

## Features

- Upload one or more PDFs and chat with them in natural language
- Retrieval-augmented generation (RAG) — answers are grounded in your document, with a citation-style "Sources" panel per response
- Streamed responses for a live, token-by-token typing effect
- Semantic (meaning-based) search via FAISS, not just keyword matching
- Adjustable chunk size, chunk overlap, and number of retrieved chunks per question
- Shows page count and chunk count for whatever you've indexed
- Supports multiple PDFs combined into a single searchable index

## How it works

Every question runs through two pipelines:

**Indexing** (once, when you click *Process documents*)
1. Extract text from each uploaded PDF
2. Split the text into overlapping chunks (so no sentence gets cut off between chunks)
3. Embed each chunk into a vector using a local embedding model
4. Load those vectors into a FAISS index for fast similarity search

**Query** (once per question)
1. Embed your question with the same model
2. Retrieve the *k* most similar chunks from FAISS
3. Paste those chunks into the LLM's system prompt as context
4. Stream the answer back from Groq, grounded in that context

## Tech stack

| Library | Role |
|---|---|
| [Streamlit](https://streamlit.io) | Web UI — turns the Python script into an interactive app, no HTML/JS written by hand |
| [pypdf](https://pypdf.readthedocs.io) | Extracts text from uploaded PDFs |
| [fastembed](https://github.com/qdrant/fastembed) | Generates embedding vectors via ONNX Runtime — deliberately chosen over `sentence-transformers`/PyTorch to keep the app lightweight and fast to boot on constrained hosting |
| [faiss-cpu](https://github.com/facebookresearch/faiss) | In-memory vector index for semantic similarity search |
| [groq](https://groq.com) | LLM inference client — streamed chat completions |
| [python-dotenv](https://github.com/theskumar/python-dotenv) | Loads `GROQ_API_KEY` / `GROQ_MODEL` from a local `.env` file |

## Getting started

### Prerequisites

- Python 3.10+
- A free [Groq API key](https://console.groq.com)

### Installation

```bash
git clone https://github.com/Mohammed-Jameal-J/RAG_Prod.git
cd RAG_Prod

python -m venv .venv
.venv\Scripts\Activate.ps1      # Windows PowerShell
# source .venv/bin/activate     # macOS/Linux

pip install -r requirements.txt

copy .env.example .env          # Windows
# cp .env.example .env          # macOS/Linux
```

Open `.env` and set your real key:

```
GROQ_API_KEY=your_actual_key_here
GROQ_MODEL=openai/gpt-oss-120b
```

### Run locally

```bash
streamlit run app.py
```

Opens at `http://localhost:8501`.

## Deployment

The app is a standard Streamlit web service — deployable anywhere that runs a persistent Python process. It is **not** compatible with static-only or serverless-function platforms (e.g. GitHub Pages, Vercel's default Python runtime), since Streamlit needs a long-lived process holding a WebSocket connection per user.

Deployed here on [Render](https://render.com) as a Web Service:

| Setting | Value |
|---|---|
| Build Command | `pip install -r requirements.txt` |
| Start Command | `streamlit run app.py --server.port $PORT --server.address 0.0.0.0` |
| Environment Variables | `GROQ_API_KEY`, `GROQ_MODEL` |

## Configuration

| Variable | Required | Description |
|---|---|---|
| `GROQ_API_KEY` | Yes | Your Groq API key. The app fails fast with a clear error if this is missing. |
| `GROQ_MODEL` | No | Groq model ID to use. Defaults to `openai/gpt-oss-120b`. |

## Known limitations

- The index is held in memory per session — it resets whenever the app restarts or the browser tab reloads. Re-upload and reprocess your PDF(s) after either.
- There's no authentication — the deployed link is open to anyone, and every question spends your Groq API quota.
- Free-tier hosting spins down after ~15 minutes of inactivity; the next request pays a cold-start cost.
